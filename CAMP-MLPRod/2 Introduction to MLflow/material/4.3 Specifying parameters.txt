9. Running parameters
01:52 - 02:26
To run our new parameterized ML code, in Python we can use the MLflow-dot-projects module with the run method or from the mlflow run command. The run method from the MLflow-dot-projects module takes an argument called "parameters". The parameters argument accepts a dictionary containing parameters. The MLflow run command accepts a dash-capital-P argument to pass a parameter to a Project. Each parameter must have its own dash-capital-P argument in the form of parameter-name equals parameter-value.
